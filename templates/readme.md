# Akrites SIRT Templates

Template files that the Akrites SIRT leverages as part of their daily operations.

- [Acknowledgement template](acknowledgement-template.md) — the first reply the SIRT sends a Finder
- [Advisory template (OSV JSON)](advisory.osv.json)
- [Case read-in notice](Akrites_Case_ReadIn_Notice_Template.md)
- [Case read-in log (CSV)](Akrites_ReadIn_Log_CASE.csv)
- [Notification templates](notification-templates.md) — acknowledgement, triage assessment, embargoed notification, public advisory, embargo-break notice
- [Vulnerability report intake template](vulnerability-report-intake-template.md)
- [WG membership register (CSV)](Akrites_WG_Membership_Register.csv)

Five further templates — the contact attempt log and the four Maintainer-of-Last-Resort records (maintainer non-fix record, MoLR decision record, project status notice, steward vetting & approval record) — are under revision in [PR #62](https://github.com/Akrites-Foundation/SIRT/pull/62) and are listed by name only until that lands.
