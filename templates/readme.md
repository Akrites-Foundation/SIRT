# Akrites SIRT Templates

Template files that the Akrites SIRT leverages as part of their daily operations.
All templates follow the Board-approved [CVD Policy](../docs/Akrites_CVD_Policy.md);
where a template and the policy disagree, the policy governs.

- [Vulnerability report intake template](vulnerability-report-intake-template.md) — what a Finder sends us

## Case communications

- [Upstream report template](upstream-report-template.txt) — the report the SIRT sends to an upstream maintainer at hand-off
- [Advisory template (OSV JSON)](advisory.osv.json)

## Read-in and working groups

- [Case read-in notice](Akrites_Case_ReadIn_Notice_Template.md) — sent to each person read into a case; see the [Read-In Policy](../docs/Akrites-Read-In-Policy.md)
