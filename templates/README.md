# Akrites SIRT Templates

Template files that the Akrites SIRT leverages as part of their daily operations.
All templates follow the Board-approved [CVD Policy](../docs/policies/cvd-policy.md);
where a template and the policy disagree, the policy governs.

## Finder-facing

- [Vulnerability report intake template](vulnerability-report-intake-template.md) — what a Finder sends us

## Case communications

- [Notification templates](notification-templates.md) — acknowledgement, triage assessment, embargoed notification, public advisory, embargo-break notice
- [Upstream report template](upstream-report-template.txt) — the report the SIRT sends to an upstream maintainer at hand-off
- [Advisory template (OSV JSON)](advisory.osv.json)

## Read-in and working groups

- [Case read-in notice](case-read-in-notice-template.md) — sent to each person read into a case; see the [Read-In Policy](../docs/policies/read-in-policy.md)
- [Case read-in log (CSV)](Akrites_ReadIn_Log_CASE.csv)
- [WG membership register (CSV)](Akrites_WG_Membership_Register.csv)
- [Vulnerability finding issue template](vulnerability-finding-issue-template.md) — opened in a Working Group's private repository
